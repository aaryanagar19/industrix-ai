# API Reference

Interactive Swagger UI: `http://localhost:8000/docs` - OpenAPI JSON: `/openapi.json`. Generated by `scripts/gen_docs.py`.

All endpoints except `/api/auth/login`, `/api/auth/register` and `/api/health` require `Authorization: Bearer <JWT>`. WebSocket: `/ws/live?token=<JWT>`.
